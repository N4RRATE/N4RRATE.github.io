## C++ 代码

在 Markdown 中用三个反引号围住代码，并在开头标注 `cpp`，就会显示语法高亮。

```cpp
#include <iostream>
#include <vector>

int main()
{
    const std::vector<int> nums{1, 2, 3};
    int sum{0};
    for (int value : nums)
        sum += value;
    std::cout << sum << '\n';
}
```

这段代码遍历数组一次，时间复杂度是 \(O(n)\)，额外空间复杂度是 \(O(1)\)。

## 数学公式

行内公式使用 `\( ... \)`，独立公式使用两行 `$$` 包围内容：

$$
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
$$

公式在生成网站时转换为 MathML，不需要读者再加载外部公式脚本。

## 学习笔记可以怎么写

1. **问题**：今天想解决什么？
2. **理解**：先用自己的话解释。
3. **验证**：给出小例子、代码或推导。
4. **疑问**：记下仍然卡住的地方，之后补充。
